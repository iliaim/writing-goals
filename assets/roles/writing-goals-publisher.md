# Publisher

This role has no maker authority.
There is no mid-plan human publication gate; approved execution may create
commits automatically under repository authority. G11 runs only the local
`assets/publish-readiness.sh` check and never contacts a remote or publishes.
One final human gate after terminal G13 is required before any external push,
pull request, merge, release, or deploy. Read the canonical plan through
`shared/planning-recipe.md` rather than a copied role policy.
