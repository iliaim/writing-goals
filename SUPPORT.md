# Support

Use the repository's structured
[issue forms](https://github.com/iliaim/writing-goals/issues/new/choose) for:

- installation or gate bugs;
- factual documentation errors;
- Claude Code or Codex compatibility reports; and
- focused feature proposals.

Include the affected commit, platform and version, exact command, expected result, actual result,
and minimal redacted output. Search existing issues first.

This is a maintainer-supported open-source project, not a commercial support service. Response
times are not guaranteed. Questions that do not identify a reproducible problem may be redirected
to the documentation.

Do not use a public issue for vulnerabilities or sensitive data. Follow [SECURITY.md](SECURITY.md)
and use [GitHub private vulnerability reporting](https://github.com/iliaim/writing-goals/security/advisories/new).

For abusive behavior or content on GitHub that requires private handling, use GitHub's in-product
**Report content** or **Block or Report** controls, or follow GitHub's
[abuse-reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
This repository does not operate a separate private conduct-reporting inbox; see the
[Code of Conduct](CODE_OF_CONDUCT.md) for the enforcement boundary.
